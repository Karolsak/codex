Problem Statement & Theory

Given: A 3φ delta-connected AC voltage controller controls the speed of a 3φ, 5 hp, 208 V, 60 Hz induction motor. At full-load: PF = 0.85 lagging, η = 90 %.

(a) Circuit: Three anti-parallel thyristor pairs (SCR pairs) are inserted in each of the three supply lines feeding the delta-connected motor. Gate pulses displaced by 120° control the RMS voltage, hence motor speed.
(b) Input kVA:
Pout = 5 × 746 = 3 730 W
Pin = 3 730 / 0.90 = 4 144 W
Sin = 4 144 / 0.85 ≈ 4 876 VA ≈ 4.876 kVA
(c) Firing Angle Range:
φ = cos⁻¹(0.85) ≈ 31.8° → αmin = 31.8°
αmax = 180° (zero output voltage)
Full-load range: 31.8° ≤ α ≤ 180°
(d) Thyristor Ratings:
IL = 4876 / (√3 × 208) ≈ 13.54 A
Iph,Δ = 13.54 / √3 ≈ 7.82 A
VTHY (PIV) = √2 × 208 ≈ 294 V
Irms,thy = 7.82 / √2 ≈ 5.53 A
(e) Waveform (PF = 0.80, α = 60°):
φ = 36.87° < α = 60° → thyristors fire after natural zero-crossing.
Each SCR conducts from 60° to β ≈ π + φ ≈ 216.9°.
Motor voltage = source during conduction, zero during blocking.
Current lags voltage by φ and decays exponentially when SCR off.

Key Equations

RMS Output Voltage (RL load, approx.)

V_out = V_s · √[ (1/π)(2(π−α) + sin2α) ]

Valid for resistive load; RL load uses actual β

Phase Current (conduction interval)

i(ωt) = (V_m/Z)[sin(ωt−φ) − sin(α−φ)·e^(−(ωt−α)/tanφ)]

Induction Motor Torque

T_e = 3V²R₂/s / [ω_s((R₁+R₂/s)²+(X₁+X₂)²)]
